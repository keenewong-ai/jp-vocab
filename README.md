# Japanese Vocabulary Flashcards

Simple static site for studying Japanese vocabulary with memo cards and text-to-speech.

## Features

- Searchable word list (Japanese / Chinese)
- Memo cards with progress stored in the browser
- Click 🔊 to hear Japanese pronunciation (browser speech synthesis)

## Local use

Open `index.html` in a browser, or serve the folder with any static file server.

## GitHub Pages

This repo is published via GitHub Pages from the `main` branch root.
